╔═══════════════════════════════════════════════════════════════════════════════════════════════╗
║                                    DATA FLOW SUMMARY                                          ║
╚═══════════════════════════════════════════════════════════════════════════════════════════════╝

1. User Query       → Frontend captures input
2. HTTP POST        → Sends to /api/query endpoint
3. Session Check    → Create or retrieve session
4. History Lookup   → Get conversation context (if exists)
5. Claude Call #1   → AI analyzes query, decides to use tool
6. Tool Execution   → Search course content in ChromaDB
7. Vector Search    → Semantic similarity search (embeddings)
8. Format Results   → Structure results + track sources
9. Claude Call #2   → AI synthesizes natural language answer
10. Store History   → Save exchange to session
11. HTTP Response   → Return answer + sources + session_id
12. UI Update       → Render markdown answer with sources
